# Dev Coffee

Buy an independent developer a coffee. People and AI agents can tip in **one HTTP request** with the [Machine Payments Protocol (MPP)](https://mpp.dev): no account, no API key, no checkout page.

Built for the MPP hackathon. Two ways to pay, both test-only (nothing real is charged): **Tempo testnet** stablecoin, or a **Stripe card via Shared Payment Token** in Stripe test mode.

## How it works

```
Agent ── POST /api/coffee {"handle":"ana"} ─────────────► Dev Coffee
      ◄── 402 Payment Required + WWW-Authenticate: Payment (price: $3, Tempo testnet)
Agent ── pays on Tempo, retries with the credential ────►
      ◄── 200 {"status":"coffee_sent", ...} + Payment-Receipt
```

| Endpoint | Paid? | What it does |
|---|---|---|
| `GET /api/devs?q=` | free | Find a developer by what they built |
| `GET /api/devs/{handle}` | free | One developer's profile |
| `POST /api/coffee` (or `GET` with query) | **$3 via MPP** | Buy that developer a coffee; returns the coffee and a receipt |
| `GET /api/coffees` | free | The public coffee wall |
| `GET /openapi.json` | free | OpenAPI 3.1 with `x-payment-info` (generated by `mppx`) |
| `GET /llms.txt` | free | What an agent needs to know, including the price |

Body for `/api/coffee`: `{ "handle": "ana", "from": "your name", "message": "thank you" }`. Unknown or missing handles go to the community jar, so every paid request gets a result. The developers are demo profiles.

## Try it

```bash
npx mppx account create                                   # free testnet wallet
npx mppx "https://<your-host>/api/coffee?handle=ana&from=me"
npx mppx validate https://<your-host> --endpoint POST:/api/coffee --body '{"handle":"ana"}'
```

## Run locally

```bash
npm install
# .env.local (never committed):
#   MPP_SECRET_KEY=<openssl rand -hex 32>
#   TEMPO_RECIPIENT=<your Tempo testnet address>
#   NEON_POSTGRES_CONNECTION_STRING=<optional; in-memory without it>
npm run dev
```

In production (Vercel) the Postgres connection is required: `mppx` uses it as the shared replay-protection store, and the coffee wall lives there.

Stack: Next.js, [`mppx`](https://mpp.dev/sdk/typescript), Neon Postgres, Vercel, provisioned with Stripe Projects.
